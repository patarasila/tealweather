Run python backend by running app.py (in python backend folder)
Make sure port 5000 is not used by any app before running this

Run website by hosting index.html on localhost (or on domain) (in website folder)
THIS WONT WORK IF U RUN FILE DIRECTLY

Make sure to have libraries: "Flask", "requests", "pandas", "datetime" and "scikit-learn".
It should preferably be installed by pip, but can be done with other package managers.
